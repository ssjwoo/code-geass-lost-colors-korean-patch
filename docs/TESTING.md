# 검증 범위와 남은 문제

## 기계 검증

- 646개 대사 자원의 최종 ISO 읽기 재검사: 통과.
- 문자열 29,461개의 문구·제어코드·글자 번호 보존: 통과.
- NativePoC1 대비 계획한 글자 그림 영역 외의 바이트 차이 없음.
- ISO/중첩 자원 구조 재검사: 통과.
- 일본판 1.01에서 차분 패치를 재적용한 결과: FontFix2 ISO와 SHA256 일치.
- 이번 배포 ZIP의 실제 Windows 적용 스크립트와 오류 방지 검사 결과는 `verification.json`에 기록합니다.

## 실행 관찰

PPSSPP 1.20.4 소프트웨어 렌더러에서 정확한 FontFix2 ISO를 새로 부팅했습니다. 해당 인스턴스에서 RAM 수정이나 상태 불러오기를 하지 않았습니다. 첫 독백, 여학생·남학생이 있는 복도 장면, 그 다음 남학생 대사에서 읽히는 한글을 관찰했습니다. 이 표본은 전수 시각 검사를 뜻하지 않습니다.

2026-10-19 사용자 실기 보고: “fix2 어느정도 되는듯.” 대상은 앞서 알려 준 PSP-3000 / 6.61 ARK-5입니다. 이번 회신에는 새 사진·카드 파일 해시·개별 통과 장면이 없으므로 **사용자 보고에 따른 제한적 개선**으로 기록합니다.

## 남은 검증과 제한

- 실물 PSP의 다른 장면·다른 폰트 구성·긴 문장 및 줄바꿈.
- 이름 입력, 저장과 불러오기, 기존 세이브 호환성.
- 전 루트와 엔딩까지의 연속 플레이.
- 공용 메뉴/제목, 이미지·로고·영상에 남은 일본어와 전체 번역 누락 조사.

문제가 생기면 릴리스 이름, 기기/커펌, 해당 화면과 직전 조작을 이 저장소 이슈에 남겨 주세요. 개인 세이브는 공개 업로드 전에 개인정보 포함 여부를 확인하세요.
