# 업데이트 내역

## v1.0 — 2026-10-24

- FontFix2의 대사 폰트 보수 유지: 646개 대사 자원의 한글·ASCII·문장부호 글자 그림 재생성.
- 21개 영상에 한국어 대사·노래·크레딧 자막 반영. 나머지 7개 영상은 원본을 유지합니다.
- 새 게임 도입부 C.C. 독백 5개에 대화창 없이 자막 표시. 원래 음성과 진행 타이밍을 유지합니다.
- 일부 영상의 큰 프레임 색인 크기 잘림 수정 및 영상 인코딩 호환성 조정.
- 실행 파일 재배치 표의 정렬 오류 수정. PSP 로고에서 멈춘 뒤 전원이 꺼지던 통합본을 보수했고, PSP-3000 / 6.61 ARK-5에서 사용자가 실행 성공을 확인했습니다.

- 일본판 1.01 원본에서 적용하는 통합 xdelta 및 Windows 검증 도구 제공. 실기 성공본의 바이트를 그대로 유지합니다.


## FontFix2 시험판 — 2026-10-19

- 실물 PSP에서 대사 글자가 조각나거나 다른 글자로 보이던 보고를 바탕으로 수정했습니다.
- 646개 ScStr 대사 자원의 한글·ASCII·문장부호 글자 그림을 Noto Sans KR 15px, weight 600으로 다시 만들었습니다.
- 문자열 29,461개, 제어코드, 글자 번호, 폰트 메트릭, 팔레트와 자원 배치를 보존했습니다. 기존 이름 표시에 필요한 가나·한자 슬롯 그림도 유지했습니다.
- 새 ISO를 PPSSPP 1.20.4에서 처음부터 부팅해 첫 독백, 보고된 여학생·남학생 장면 및 다음 남학생 대사의 가독성을 확인했습니다.
- 사용자가 PSP-3000 / 6.61 ARK-5에서 제한적인 개선을 보고했습니다. 전체 정상 동작이나 완주 확인으로 확대하지 않습니다.
- 일본판 1.01에서 바로 적용하는 통합 xdelta 패치, Windows 적용 도구, SHA256 검증과 한국어 안내를 공개했습니다.

## NativePoC1 — 2026-10-18, 비공개 중간 빌드

- 커널 Launcher를 거치지 않는 게임 모듈의 직접 실행 경로를 구성했습니다.
- SOP0 및 UNION 참조 크기/위치를 정정하고 기존 PATCH2/PATCH3 효과를 UNION 쪽에 통합했습니다.
- 기동 후 대사까지 도달했으나 사용자 PSP 사진에서 글자 깨짐이 확인되었습니다. 이 중간 빌드를 다운로드 대상으로 제공하지 않습니다.

## 이전 조사 — 2026-10-18

- 사용자 제공 일본판 1.01과 기존 한글판의 자원 구성을 비교하고 1.01 보수를 기준으로 정했습니다.
- 초기 Fix1 및 asset_fix2는 미검증/폐기 실험입니다. FontFix2와 혼용하지 않습니다.
