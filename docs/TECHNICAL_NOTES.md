# v1.0 기술 기록

실기 성공본 AlignFix1을 그대로 패치 대상으로 고정했습니다. ISO 이름만 v1.0으로 안내하며 내부 XMB 제목과 진단 코드는 변경하지 않았습니다.

이전 통합본의 ELF32 재배치 표 6개가 4바이트 경계에서 2바이트 어긋나 있었습니다. 섹션 문자열표 확장 뒤 sh_addralign=0을 그대로 사용한 재배치가 원인이었습니다. 재배치 표에 최소 4바이트 정렬을 강제하고 패딩과 파일 오프셋을 수정했습니다. 로드되는 모든 코드·데이터, 재배치 항목 내용·순서, 영상과 C.C. 자막은 바이트가 유지됩니다. MIPS 워드 읽기 시험은 이전 표에서 정렬 오류, 수정 표에서 통과했습니다. 이후 사용자가 실기 실행 성공을 보고했습니다.

부팅 추적은 첫 게임 진입·화면 출력·MPEG 초기화·헤더·첫 영상 데이터·디코딩의 시작/복귀를 CG_FULL_TRACE.BIN에 기록합니다. 로그가 없다는 사실만으로 특정 실패 지점을 확정할 수 없습니다. PSP 설정이나 게임 저장 데이터에 추가로 쓰는 기능은 없습니다.

영상 21개 교체와 C.C. 라이브 장면 자막 5개를 포함합니다. 영상 자막의 압축 음성은 원본을 보존했습니다. 영화 파일 전체 재생의 실기 통과 및 전체 번역 검수는 별도 과제입니다.
