# 기술 변경과 원인 판단의 범위

실패 빌드의 문자열을 메타데이터로 읽으면 올바른 한국어였지만, 실제 글자 그림으로 조립한 문장은 깨져 있었습니다. 문자열·제어코드 왕복 검증만으로 글자 그림의 정확성까지 증명할 수는 없었습니다.

동일 장면에서 문자열·폰트 메타데이터를 보존한 채 SOP0의 글자 그림 픽셀만 교체한 진단 실험으로 읽히는 한국어가 나타났습니다. 이를 바탕으로 646개 ScStr의 한글·ASCII·문장부호 그림을 다시 만들었습니다. 원래 제작기의 어떤 버그로 그림이 잘못 생성되었는지는 확정하지 않았습니다.

FONTDATF의 격자 열·행은 명시 필드를 사용했습니다. 텍스처 폭을 셀 폭으로 나눈 값으로 대체하지 않았습니다. 별도 폭 필드를 32에서 512로 바꾸는 실험은 개선이 없어 채택하지 않았습니다. 일부 가나 메타데이터에 한국어 이름용 그림이 들어 있으므로 그 슬롯은 유니코드 이름만 보고 다시 그리지 않았습니다.

FontFix2의 직접 변경은 NativePoC1 대비 GIM 픽셀 영역에 한정됩니다. 배포 차분은 일본판 1.01부터 같은 최종 ISO를 재현하므로 기존 번역, 직접 게임 모듈 실행, SOP0/UNION 참조 보수 및 기존 이름 폰트 오버레이의 통합도 함께 포함합니다.

소스 이미지 식별 → xdelta 적용 → 최종 크기·SHA256 확인이 배포 도구의 필수 경로입니다. 다른 판본이나 손상된 패치/디코더를 자동 대체하지 않습니다.
