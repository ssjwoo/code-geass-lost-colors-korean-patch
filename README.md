# 코드기어스 LOST COLORS 한글패치 v1.0

PSP 일본판 **1.01 / ULJS00135**용 정식 1.0 통합 패치입니다. 실기 부팅이 확인된 AlignFix1과 **동일한 ISO 바이트**를 생성합니다. FontFix2를 먼저 적용할 필요 없이 패치 전 원본에 바로 적용합니다.

## 다운로드와 적용

1. `Code_Geass_KO_v1.0_patch.zip`을 받아 별도 폴더에 풉니다.
2. `Apply-Fix.cmd`를 실행하고 직접 보유한 일본판 1.01 원본 ISO를 선택합니다.
3. 검사가 끝나면 `output/Code_Geass_KO_PSP_v1.0.iso`가 생성됩니다. 평소 방식으로 PSP 메모리카드의 `ISO` 폴더에 복사합니다.

원본 파일은 보존됩니다. 이미 패치한 ISO와 일본판 2.00은 입력으로 지원하지 않습니다. 개별 `.xdelta` 파일도 함께 제공하며, 수동 적용 시 `xdelta3 -d -s 원본.iso 패치.xdelta 결과.iso`를 사용할 수 있습니다. 원본·결과·패치 해시는 `CHECKSUMS.md` 및 `manifest.json`에 있습니다. 게임 ISO는 배포하지 않습니다.

## 주요 변경

- FontFix2의 대사 폰트 보수 유지: 646개 대사 자원의 한글·ASCII·문장부호 글자 그림 재생성.
- 21개 영상에 한국어 대사·노래·크레딧 자막 반영. 나머지 7개 영상은 원본을 유지합니다.
- 새 게임 도입부 C.C. 독백 5개에 대화창 없이 자막 표시. 원래 음성과 진행 타이밍을 유지합니다.
- 일부 영상의 큰 프레임 색인 크기 잘림 수정 및 영상 인코딩 호환성 조정.
- 실행 파일 재배치 표의 정렬 오류 수정. PSP 로고에서 멈춘 뒤 전원이 꺼지던 통합본을 보수했고, PSP-3000 / 6.61 ARK-5에서 사용자가 실행 성공을 확인했습니다.

## 확인 범위와 남은 항목

- 실기 확인은 사용자 실행 성공 보고 범위입니다. 전 루트 완주, 모든 영상의 실기 재생, 저장·불러오기 전수 검증은 완료하지 않았습니다.
- PC에서는 동일 ISO의 부팅, 오프닝 자막, C.C. 자막 5개, 오프닝 건너뛰기와 이어지는 일반 대사를 확인했습니다.
- 기존 번역의 전체 원문 대조 및 일부 영상 청취·표현 검수는 남아 있습니다. 영상 04/07/12/19의 일부 표현과 17의 짧은 소리는 추가 확인 대상입니다. 버전 1.0은 전 항목 검수 완료나 100% 한글화를 뜻하지 않습니다.
- 검증된 실행 파일을 그대로 배포하므로 PSP 목록 이름은 **CG LC - ALIGN FIX 1**입니다. 부팅 기록용 `CG_FULL_TRACE.BIN`이 카드 최상위에 생성될 수 있으며 실행 시 다시 작성됩니다(정상 관찰 208바이트). 게임 저장 파일과 별개입니다.

문제 보고 시 패치 버전, PSP 모델/펌웨어, 발생 장면과 증상을 이슈에 남겨 주세요. 로그를 첨부할 때는 위 진단 파일만 사용하고 저장 데이터 등 개인 파일은 제외해 주세요.
